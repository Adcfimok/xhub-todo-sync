## 3.0.0：手机 ⇄ 电脑文件传输（大版本）

- 协议：2 MiB 分块，手机→电脑写 `.data/files/tmp/<id>.part`，完成后 SHA-256 校验改名进 `inbox/`；电脑→手机现场加密下发，手机落 `下载/x-hub/`
- 加密：HKDF-SHA256(token, salt=transferId) → AES-256-GCM；nonce=sha256(id)[0..4]||BE64(index)，AAD 绑定 id/index/size
- 坑 1：Java HKDF 把 token/id 写反（hmac key 应为 salt），key 与 Node 不一致 → 用 `_tools/crypto-interop-check.mjs` 反射真实类逐字节对拍才发现
- 坑 2：扩展 iframe 不能直连 127.0.0.1，`window.xhub.service.request` 只收字符串 → 电脑端改 1 MiB base64 分块，服务端 `appendLocal(id, offset, buf)` 兼容裸二进制与 `{off,data}`
- 坑 3：本机解析 `off` 时 `Number(null)=0` 把缺省当 0 → 已改为 NaN 判断
- 服务端：`service/files.js`（配额 2 GiB、单文件 512 MiB、24h 待接收、14 天清理、文件名清洗、风险扩展名、审计 file-receive/file-send）
- 安卓：`FileTransfer.java`（SAF 读流、分块、5 次退避重试、MediaStore 落盘、断点 .part）；`pages/transfer.js` 有「未完成的发送 → 继续」入口
- 设备级开关 allowFiles（老设备 undefined 视为允许）；本机 /api/local 仍受 Sec-Fetch-Site 保护
- 测试：files 37、files-ui 9、android-transfer 15、crypto-interop 6、e2e 41、security 28、home 88、单测 46、nav 两套全绿
- 产物：APK 245,092B SHA 3ebaf3bf…；扩展 91,728B SHA 706b816f…

## 3.2.0：底栏闪动修复 + 教务系统一键导入内置
- 用户实测「底栏滚动换页时窗口闪动」。根因两条：① `.tab-indicator > i` 的 `backdrop-filter: blur(14px)` 在跟手移动时每帧重采样背景；② 松手后 `--tab-i` 要等 `hashchange` 才更新，高亮块先弹回原格再跳到目标格。另有 `void offsetWidth` 强制同步布局加剧重排。
- 修法：内层模糊改半透明实色 + `translate3d` 合成层；拖拽期连胶囊模糊也关（`background: var(--bar)`）；`finish()` 松手即写目标 `--tab-i` 并加 `.snapping` 弹性过渡；点按脉冲改 WAAPI `element.animate()`（CSS `.switching` 规则保留给 nav-v5 断言）；手势切页跳过脉冲；`render()` 加 opacity 淡入 + 按页面记忆 `.scroll` 的 scrollTop。
- 灵敏度：起手 6→3px、方向判定放宽、pointermove 用 rAF 合帧、阻尼 0.32→0.18；轻扫判定最终定为「时长 <400ms 且 8<|d|<0.6unit 且 steps=0 补一格」，**不依赖瞬时速度**（不同 WebView 的 pointer timeStamp 精度差异会让判定飘；把速度折算成位移又会让普通拖动多跳一格）。这个取舍经两轮实测调出来的。
- 教务导入：依据桌面 `WakeUp课程表_6.5.2/assets/empty.html` 原文（「输入网址→点确定→点到课表界面→点右下角导入」）实现流程；`school_info_android_new.txt` 是加密学校库，未解密/未内置/未编造校方地址，网址由用户填。主 Activity 叠一层独立 WebView（FrameLayout 根布局），Java 不向外部页面暴露 JS 接口，`evaluateJavascript` 返回值用 `JSONTokener` 解出 HTML，24KB 分块 `edu` 事件回传前端。
- 新增 `lib/edu.js`（纯函数，可 Node 测）：JSON/嵌套接口 JSON/正方·URP HTML 表格三类解析，星期/节次/多段周次/单双周/教师/地点归一；`parseWeeks("2-3,8-17")` 拆两条。用桌面真实 `教学安排表.json` 实测 33 条 / 11 门全识别；单测用脱敏同结构样本。
