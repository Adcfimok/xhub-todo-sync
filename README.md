## 三句话

1. **分析**：x-hub 是 Tauri + Vue 桌面工作台；扩展是无构建的静态 HTML，跑在跨源 iframe 里、只能经注入的
   `window.xhub` 桥访问宿主数据；扩展可带 Node 后端，官方支持绑 `0.0.0.0` 对外监听。
2. **规范**：工作台是 12 列网格，卡片内容区是 `container-type: size` 的查询容器，最矮只有约 34px。
   规范把几何、字号阶梯、间距、语义色、溢出策略固化成一页可照抄的纸。
3. **实现**：中枢在后端（变更日志 + HLC + 记录级 LWW），两端都是它的对等客户端；
   手机端本地优先、断网可用；AI 走电脑中转，扩展在手机 iframe 里跑、数据由电脑页面代答。

## 手机端能做什么

- **待办**：新建/编辑/勾选/删除、分组、优先级、截止时间、备注；卡片按内容自适应高度，长标题长备注不截断
- **日历**：首页卡片一键进月历，待办按截止日期落在格子上，红点标逾期、点某天看当天并新建
- **账号**：x-hub 账号登录（邮箱/GitHub）、兑换邀请码、开发者申请、平台免费 AI 额度
- **AI 内置配置**：DeepSeek/OpenAI/月之暗面/百炼/Ollama 预设一键填充；**手机直连供应商，不依赖电脑**；测试连通 / 获取模型
- **AI 操作待办**：直接说「明天三点提醒我交房租」，助手会真的建/改/删待办（工具调用，删除前确认）
- **磨砂底栏**：酷安式悬浮胶囊（首页/待办/笔记/＋/AI/我的，整条上移到拇指区），手指拖拽时高亮药丸实时跟随、松手吸附；中央 ＋ 随页面变成新建待办/笔记/速达/提示词
- **番茄钟**：扩展页内置工具，25 分钟专注 + 5 分钟休息，到点通知
- **提醒**：待办到期前 15 分钟发系统通知
- **剪贴板**：新建待办一键粘贴剪贴板内容
- **笔记**：列表、全文搜索、编辑
- **便签**：两槽位，自动保存
- **速达**：网页一键打开
- **提示词**：搜索、复制、置顶
- **AI**：任意 OpenAI 兼容接口，流式对话，密钥只在手机
- **扩展**：直接运行电脑上装的 x-hub 扩展（样式完整、可读真实数据）
- **同步**：配对、设备管理、冲突记录与恢复、主题

搬不了的是桌面形态专属能力（剪贴板历史、系统监控、悬浮球、钉图、录音）和宿主没有数据接口的功能（倒计时）。
逐条理由见 `docs/05`。

## 快速开始

**装扩展**：扩展中心 →「我的扩展」→ 添加 `extensions/todo-relay`（或解压 `dist/` 里的 zip 后指向该目录）。

**装 App**：安装 `android/todo-link-2.8.0.apk`，底部「我的 → 同步与设置」输入电脑地址与 6 位配对码，或扫码。

### 配对不上怎么查

同一 Wi-Fi 却连不上，九成是「地址给错了」，不是网络问题。按顺序看页面上的三处：

1. **主地址旁边有没有「默认路由」标签**。没有就说明后端没探测到默认路由，换一张网卡或重开扩展。
2. **主地址是不是虚拟网卡**（VMware / VPN / WSL 的地址同样长得像内网）。标签里出现「虚拟网卡」或红条会直接提示，
   这时点「换配对码」重试，或从下面列表里点物理网卡地址复制给手机。
3. **手机端扫码而不是手输**。二维码已是 v3，里面带最多 4 个候选地址，手机会逐个试，手输只有一个。

仍然不通，在电脑浏览器打开 `http://127.0.0.1:47821/api/v1/diag`，看 `verdict` 与 `addresses`；
再用手机浏览器打开 `http://<主地址>/healthz`，能返回 `{"ok":true}` 说明网络通、问题在配对码。

### 数据读不到

扩展页「同步内容」下方写着读取/写回范围。若出现红字「缺少读取权限」，点红字下方的「打开扩展权限设置」，
把 `data:read` 打开后重新同步即可；已同步过的数据不会因为撤销权限被清空。

## 两条硬限制

- 扩展的 `data.*` 由电脑端「待办同步」整页代答：页面关着时扩展会显示「电脑端页面未打开」。
  开扩展的「常驻后台」即可消除（x-hub 0.9.4+）。
- 局域网明文 HTTP，靠令牌准入。公共 Wi-Fi 下不建议开启。
