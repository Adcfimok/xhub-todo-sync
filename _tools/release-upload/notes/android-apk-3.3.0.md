# 安卓端 3.3.0（versionCode 27）

AI 助手新增历史对话管理：自动保存所有对话，可查看、继续、单条/批量删除，新建对话不再丢历史。

## 新增与改进

- **自动保存**：每次提问先落盘，回复结束（成功 / 失败 / 主动停止）再落盘一次；单会话保留最近 60 条，与旧行为一致。
- **历史列表**：顶部「历史 N」打开面板，按今天 / 昨天 / 更早分组，显示标题、最后一条预览、时间与消息数；当前会话高亮并标「当前」。
- **查看与继续**：点一条即载入完整消息并滚到最新，之后提问会把上下文续在这条会话上，不会串到别的对话。
- **删除**：单条与批量选择都先弹确认（单条带标题、批量带条数），取消或点遮罩都不删；删除的是消息数据本身，不留空壳；删掉当前会话会自动回到新对话草稿态。
- **新建对话**：只把「当前指针」拨回草稿态，历史一条不动，也不再需要二次确认。
- **清晰区分**：状态条 `✦ 新对话 · 发第一条消息后自动保存` 与 `↺ 历史对话 · <标题> · N 条` 两种样式；空状态引导语也不同。
- **懒创建**：新对话只有发出第一条消息才落库，反复点「+ 新对话」不会堆出空会话。
- **模型没配好也能看历史**：未配置引导页新增「查看历史对话（N）」入口；换模型 / 清 Key 不会让旧对话消失。
- **设置面板统一**：原来的「清空对话」改为「删除当前对话」，与历史列表走同一套确认与删除逻辑。

## 数据存储方案

全部落在现有 IndexedDB 的 `meta` store，**不升 DB_VER、不新建 object store**（零 schema 变更，覆盖安装无迁移风险）：

| key | 内容 |
| --- | --- |
| `aiSessions` | 会话索引（id / 标题 / 创建与更新时间 / 条数 / 预览） |
| `aiChat:<id>` | 单个会话的消息数组 |
| `aiActiveId` | 当前会话 id，`''` = 新对话草稿 |
| `aiMigrated` | 旧 `aiMessages` 迁移标记 |

索引、消息体、指针由 `core.js` 新增的 `applyMeta()` 在**同一个事务**里写入 / 删除。
`meta` 不在 PROTO 2 同步载荷内（同步只推 records 脏记录），所以**历史只留在这台手机**，
不会把聊天文本推给电脑，协议也不变。旧版 `aiMessages` 首次进入时自动转成一条历史会话并续上，不丢记录。
详见 `docs/15-AI历史对话管理.md`。

## 兼容性与边界

- 同步协议仍是 `PROTO 2`，`versionCode 27` 可直接覆盖安装，本地待办与旧聊天记录都保留；签名证书与 3.2.0 一致。
- 历史只在本机，不做云备份 / 导出；卸载或清除数据会一起消失。
- 单会话上限 60 条（裁最早）、历史会话上限 100 条；达到 100 条会提示先删除，**不会自动清理**用户数据。
- 标题自动生成，本版不支持重命名、搜索或按标题筛选。
