## 新增：AI 多模型接入与选择

- **模型清单**：x-hub 内置模型与自备 OpenAI 兼容接口统一为一个可选列表；平台清单来自 `/api/v1/ai/models`，登录后自动拉取并缓存，服务端加减模型会多退少补。
- **两个入口**：AI 助手顶部新增当前模型胶囊（点击切换）；设置页「模型设置」按分组列出全部模型与当前项，支持添加 / 编辑 / 删除自备模型、测试连通、获取模型。
- **课表识别前确认**：`AI 识别 PDF 课表` 与 `粘贴文字让 AI 识别` 都会在真正发请求前弹出「选择识别模型」，取消则不发请求；进度卡片显示实际使用的模型。
- **默认与作用域**：未选择时默认 x-hub 平台清单第一条（未登录则第一个自备模型）；切换立即生效、全局共用（AI 助手 + 课表识别）、写入本机 `meta`，重启保留，不跨设备同步。
- **不可用回退**：所选模型被删除 / 平台下架 / 退出登录时自动落到可用模型并提示；请求返回 `model_not_allowed` 会重新对账并自动重试一次；缺 Key / 未登录的模型在列表中标红且禁止确认。

## 兼容与迁移

- 首次启动自动把旧版 `aiPlatform/aiBase/aiKey/aiModel` 迁移成一条模型，并把默认选择写入 `aiSelected`；
- 旧键继续双写，降级到 3.7.x 仍可按原逻辑对话；
- 平台模型只写 `aiPlatform` 与 `aiModel`，账号 token 不会写进 `aiKey`。
