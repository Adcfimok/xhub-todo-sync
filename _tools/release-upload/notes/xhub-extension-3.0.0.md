# 扩展 3.0.0

新增「文件传输」面板：电脑 ⇄ 手机直传，与待办同步共用同一套配对与局域网服务。

## 新增

- **文件面板**：选择/拖入文件发送到手机、逐文件进度、待接收与收件箱两列、复制路径、删除/清空。
- **设备级权限**：每台已配对设备新增「文件 开/关」，关闭后该设备所有文件接口返回 403。
- **服务端**：分块落盘、断点、SHA-256 校验、2 GiB 配额、24 小时待接收、14 天清理、磁盘余量检查。
- **加密**：令牌派生 HKDF-SHA256 → 每块 AES-256-GCM，AAD 绑定任务与块序号；手机上传时服务端解密，电脑下发时服务端现场加密。
- **审计**：收发完成写 `file-receive` / `file-send`，含设备、文件 id、文件名、时间，可从 `/api/admin/audit` 查。
- **新增自检**：`tests/files.mjs`（37 项）覆盖配对、越权、路径穿越、分块、篡改、重启续传、哈希失败、拒收、权限开关。

## 兼容性

- 扩展 `2.2.3 → 3.0.0`，同步协议不变（`PROTO 2`）。
- 旧 APK（≤2.12.4）连新扩展：同步完全不受影响，只是没有文件入口。
- 新 APK（3.0.0）连旧扩展：文件接口 404，手机端提示升级电脑端；同步仍正常。
- 新目录 `.data/files/`（inbox/out/tmp/index.json），不影响 `hub.json`；卸载扩展不会删用户文件。
