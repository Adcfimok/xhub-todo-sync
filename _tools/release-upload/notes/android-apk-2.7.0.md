x-hub 工作台的安卓客户端，本地优先、断网可用，局域网内与电脑端双向同步。

## 本版能力

- 待办 / 笔记 / 便签 / 速达 / 提示词五类数据的本地库与列表页
- 「我的 → 同步与设置」填写电脑地址与 6 位配对码，或扫码配对
- 番茄钟、AI 对话（可直连供应商，也可走电脑中转）
- 磨砂胶囊底栏，中央 ＋ 按页面切换新建类型

## 与 v2.8.0 的关系

v2.7.0 使用单一地址配对：手输或扫码只得到一个地址，电脑端选错网卡（虚拟网卡、VPN）时连不上。
v2.8.0 起二维码升级为 v3，带最多 4 个候选地址并逐个重试，同时修复同局域网配对失败。
两版签名证书相同，可直接覆盖升级，本地数据保留。

## 安装

1. 下载 `todo-link-2.7.0.apk`，允许「安装未知来源应用」。
2. 安装后打开「我的 → 同步与设置」，输入电脑端显示的主地址与配对码。
3. 配对成功后首页即出现待办卡片与五类计数。

## 校验

```bash
# 签名与包信息
apksigner verify --print-certs todo-link-2.7.0.apk
aapt dump badging todo-link-2.7.0.apk | head -2
```

资产 SHA-256 见本页附件信息，或 `node _tools/release-upload/verify.mjs` 输出。
