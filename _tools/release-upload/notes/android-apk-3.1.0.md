# 安卓端 3.1.0（versionCode 25）

大版本更新：新增称呼、课表、倒数日、桌面小组件，并增强后台保活与底栏动效。

## 新增

- **首次称呼设置**：首次打开弹出「希望我怎么称呼你」强制弹窗（不可关闭），提交后应用到首页问候、AI 对话与每日一句；「我的 → 称呼」可随时改。
- **每日一句称呼替换**：语料新增 `{name}` 占位，设置称呼后自动替换成你的称呼（未设置回退「朋友」）。
- **课表**：我的 → 课表，支持手动录入课程（星期/节次/单双周/周次）、按周查看、开学日期、JSON 剪贴板导入导出；教务系统一键导入为后续版本预留接入位。
- **今日课表卡片**：首页新增，只展示当天课程。
- **倒数日**：我的 → 倒数日，记录重要日子；首页卡片展示天数，支持左右滑动翻页切换下一个倒数日。
- **底栏动效（酷安式）**：点击图标做「放大 → 回弹 → 落定」果冻弹跳，高亮块切换带 overshoot 回弹；拖拽跟手放大保留。
- **后台保活**：设置 → 后台运行，低优先级前台服务保活，后台也能收提醒与同步（通知栏常驻一条）。
- **桌面小组件**：可添加到桌面，展示待办摘要与今日课表。

## 兼容性

- 同步协议仍是 `PROTO 2`，`versionCode 25` 可直接覆盖安装，本地数据不受影响。
- 课表/倒数日/称呼都存本地，不依赖电脑。
