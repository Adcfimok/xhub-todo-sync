# 安卓端 2.12.3（versionCode 22）

修 2.12.2 升级后「统计卡与日历之间空一整行」的问题：统计卡收高后，下面的卡片没有跟着上移，首页中间留下约 88px 的空白。

## 原因

2.12.2 把统计卡从 2 行改成 1 行，升级时只改了统计卡自己的高度，下面各卡的 `y` 还是老坐标：

```
升级前：quote y0 · stats y1–y2 · calendar y3 …
升级后：quote y0 · stats y1 · calendar y3 …   ← y2 空了整整一行
```

## 修法

- 升级流程加一步「向上压实」：所有卡片按 `y`、`x` 排序后依次往上推，推不动为止。只会上移，不会横向移动、不会下移，卡片之间的上下顺序不变。
- 布局版本 `LAYOUT_V` 2 → 3。装过 2.12.2 的机器（存档里已经是 v2、带空行）这次也会走一遍压实，不需要清除数据。
- `compact()`（删卡/加卡时用的压实）改成复用同一个 `pullUp()`，避免两套压实现日后跑偏。

## 验证

```
node _tools/home-check.mjs      # 85 项：新增「卡片之间没有空行」×3 视口 + 老布局升级 4 项
node --experimental-default-type=module --test android/tests/*.test.mjs   # 46 项（home-layout 12 项）
```

新增的回归点是拿 2.12.2 真实写回的存档复现的：

- 塞一份 `v2` 布局（统计 y1、日历 y3）→ 载入后日历 `y=2`，统计卡与日历间距实测 **10px**（就是网格标准间距）
- 载入后自动回写为 `v3`，且回写的坐标已经是压实后的
- 三档视口都断言「每张卡正上方必须有邻居」，杜绝任何形式的空行
