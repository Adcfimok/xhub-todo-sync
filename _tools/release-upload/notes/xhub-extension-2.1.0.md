# 待办同步扩展 · x-hub v2.1.0

把桌面工作台的待办 / 笔记 / 便签 / 速达 / 提示词同步到安卓手机，并为手机端提供扩展宿主与 AI 中转。

## 本版内容

- **分发包补入 `service/netinfo.js`**：上一版压缩包缺该文件，解压到扩展目录后 Node 后端会因找不到模块起不来；
  本包解压到空目录实测 `/healthz` 与 `/api/v1/diag` 正常。
- **网卡选路**：后端用 UDP `connect(223.5.5.5:53)` 取默认路由，按「默认路由 +1000 / 物理网卡 +100 / 虚拟网卡 −100」
  排序候选地址，主地址优先给手机；页面在主地址旁标注「默认路由」，虚拟网卡会额外提示。
- **二维码 v3**：载荷为 `xhub://3/<配对码>/<ip:port,...>`，最多带 4 个候选地址，手机逐个尝试，
  解决「同一 Wi-Fi 却配对不上」里最常见的地址给错问题。
- **五类数据同步**：`todos / notes / resources / snippets / stickies`；HLC + 记录级 LWW，墓碑保留 30 天。
- **权限与诊断**：`data:read / data:write / network / notify`；页面直接显示读取与写回范围，
  缺 `data:read` 时给红字提示与「打开扩展权限设置」按钮。

## 安装

1. 下载 `com.zhou.todo-relay-2.1.0.zip`，解压到任意目录（不要只解压一半，`service/` 必须完整）。
2. x-hub → 扩展中心 → 我的扩展 → 添加扩展，指向解压后的目录（含 `manifest.json`）。
3. 打开扩展页，确认主地址带「默认路由」标签；手机端扫码或手输地址 + 6 位配对码。

## 环境要求

- x-hub 桌面版 0.9.4+（常驻后台能力）
- 扩展后端为 Node 18+，监听 `47821`
- 电脑与手机同一局域网；明文 HTTP + Bearer 令牌准入

## 已知限制

- `data.*` 由电脑端「待办同步」页面代答，页面关闭时扩展会显示「电脑端页面未打开」。
- 公共 Wi-Fi 下不建议开启：协议为局域网明文 HTTP，仅靠令牌准入。

## 校验

```bash
# 解压后
node service/index.js            # 应打印监听 47821
curl http://127.0.0.1:47821/healthz   # {"ok":true}
curl http://127.0.0.1:47821/api/v1/diag
```

资产 SHA-256 见本页附件信息，或 `node _tools/release-upload/verify.mjs` 输出。
