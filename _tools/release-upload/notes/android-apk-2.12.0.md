# 安卓端 2.12.0（versionCode 19）

三处界面调整：首页首屏时间与问好合到一行、四个统计数字各自独立成卡（与「每日一句」同宽同高）、「我的 → 节日」新增「一键添加所有节日」。

## 改了什么

| 位置 | 之前 | 现在 |
| --- | --- | --- |
| 首页首屏 | 大号时钟一行、问好另起一行（26px 独占一行，占掉约 40px 高度） | 同一行：时钟 38px + 问好 18px，按基线对齐，问好降到次要层级；跨过 6/11/14/18 点时问好随时钟一起变，不用等整页重渲染 |
| 首页统计 | 一张 4×2 的「统计」卡，里面挤四个 1 列宽的小格（约 74×62px） | 拆成四张 4×1 卡片：待办 / 笔记 / 速达 / 提示词，每张与「每日一句」完全同宽同高（几何实测 366×78 @390 宽），整卡可点直达对应页面 |
| 我的 → 节日 | 只有一条进入节日页的入口，节日待办要一个个点 | 条目下方新增「一键添加所有节日」开关：一次把未来 13 个月的 54 个节日写成待办（早上 9 点到期、提前 1 天提醒），可一键撤回 |

## 细节

- **统计卡拆分**：卡片库从 10 项变 13 项；老版本存下的「统计」卡会在读取布局时自动拆成四张，日历等后续卡片顺延，不会出现「升级后统计消失」。迁移是幂等的，重复读写不会多出卡片。
- **整卡可点**：统计卡整张是点击区（`role=button` + 键盘 Enter/Space），编辑态下点击不跳页，避免拖拽误触。
- **批量添加**：同名同一天的待办只认一条，重复勾选不会堆重复项；取消勾选只删这一批自己建的、且还没做完的（已完成的当历史留着），删前弹确认。
- **空态文案**：待办卡副标题按「今天到期 N 件 / 今天完成 N 件 / 今天没有到期的」自动切换。
