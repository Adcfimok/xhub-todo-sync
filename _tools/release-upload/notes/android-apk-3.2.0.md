# 安卓端 3.2.0（versionCode 26）

修复底栏滑动换页时的窗口闪动，提升跟手度；把 WakeUp 课程表式的「教务系统一键导入」真正内置；补齐每日一句成对引号。

## 修复与改进

- **底栏切页闪动**：定位到两个根因并分别处理。
  1. 高亮块内层原本带 `backdrop-filter: blur(14px)`，跟着手指移动时 WebView 每帧重新采样背景 → 整窗闪一下；已改为半透明实色 + 合成层位移（`translate3d`），拖拽期间连胶囊本体的模糊也一并关闭。
  2. 松手后要等 `hashchange` 才更新 `--tab-i`，高亮块会先弹回原格再跳到目标格；现在松手即把目标格写入，位移连续，另加弹性吸附过渡。
  同时移除点按脉冲里的 `void offsetWidth` 强制同步布局（改用 Web Animations），手势切页不再叠加果冻动画。
- **滑动灵敏度 / 丝滑度**：起手阈值 6px → 3px；方向判定放宽；`pointermove` 用 `requestAnimationFrame` 合帧写样式；边界阻尼 0.32 → 0.18；新增「短促轻扫」判定（位移不足半格但划得快也能翻一格），普通拖动仍严格按位移吸附，不会误跳多格；切页后按页面记忆滚动位置，不再跳回顶部。
- **教务系统一键导入**：按 WakeUp 课程表 6.5.2 的流程实现（其 `assets/empty.html` 明确写着「输入网址 → 点确定 → 点到课表界面 → 点右下角导入」）。课表页「导入 → 教务系统一键导入」→ 填学校教务首页地址 → 在 App 内置浏览器里自己登录 → 点到课表页 → 点顶部「导入当前页」→ 抓取页面 HTML（含同域 iframe、抹掉密码框的值）→ 本机解析 → 预览 → 覆盖 / 追加写入。
  - 解析器支持教务导出的 JSON（如 `course_name / weekday / period_start / period_end / weeks / location / teacher`）、嵌套接口 JSON（`kbList / data / rows` 等）、以及正方 / URP 风格的课表 HTML 表格；多段周次 `2-3,8-17` 会拆成多条记录，单双周、节次、教师、地点一并识别。
  - 额外提供「粘贴 JSON / 页面源码」「粘贴 HTML 源码」两条兜底路径，浏览器预览环境也能用。
- **每日一句**：补齐右引号，卡片由原来的单个 `“` 改为 `“ … ”` 成对显示。

## 兼容性与隐私

- 同步协议仍是 `PROTO 2`，`versionCode 26` 可直接覆盖安装，本地数据不受影响；签名证书与 3.1.0 一致。
- 教务账号密码只输在教务系统自己的页面里，本 App 不读取、不保存、不上传；抓到的页面源码只在内存中分块传给本机页面解析，不落盘、不出网。

## 已知限制（如实说明）

- **学校教务网址需自己填**：各校地址不同且会变，WakeUp 自带的学校库是加密资源，本版没有内置也没有编造校方地址；类型选项只影响操作提示。
- 解析器覆盖 JSON 与常见表格结构；若某校课表是纯脚本绘制、无 `<table>`，或一格塞了多门不同周次的课，可能识别不全 —— 此时用「粘贴源码」或手动录入补齐，不会凭空猜造课程。
- 桌面小组件仍需长按桌面手动添加（3.1.0 起如此）。
