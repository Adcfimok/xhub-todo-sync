## 本版变更

### 1. 底栏收成 5 格

`首页 / 待办 / ＋ / AI / 我的`。笔记不再占底栏格子，但功能没少——它变成了二级页，入口挪到三处。

改的时候同步改了四个常量（`SLOT_ROUTE`、`TAB_SLOTS`、`VALID_SLOTS`、`TAB_OF`）和两处样式（网格列数、高亮块宽度）。高亮块的位移仍按「第几格 × 自身宽度」算，所以格数变了不用改公式，但**必须实测**——这类改动最容易出的问题就是高亮块压在格子缝上。

### 2. 笔记的三处入口

| 入口 | 位置 |
| --- | --- |
| 「我的」菜单第一项 | 带条目数量角标 |
| 首页统计格「笔记」 | 四宫格第二个 |
| 首页「最近笔记」卡片 | 每一行可点，「全部」按钮也进得去 |

笔记现在按二级页处理：返回键回到进来时的页面（从首页进就回首页，从「我的」进就回「我的」），底栏高亮也跟着来源走。以前它是底栏页，这段逻辑不存在，不补的话从「我的」进去按返回会直接跳回首页。

### 3. 加号改成先选类型

点＋弹出「待办 / 笔记 / 提示词」三项，选完再进对应表单。这是笔记移出底栏后的必要路径——否则新建笔记只能从「我的」逐层点进去。

页面自己有新建语义时仍然优先：在待办页点＋直接建待办，在日历页点＋按选中的那天建待办，不会弹选择器。

### 4. 底栏动效

参考给的示例视频（酷安底栏）做的，三件事：

- **拖动放大**：高亮块跟着手指移动时按拖动进度放大，拖满一格到 1.15 倍，松手回落到原尺寸。块本身也从圆角矩形变成更接近圆形（`border-radius` 过渡到 46%）。
- **边缘彩虹色散**：拖动时高亮块边缘浮出一圈 conic 渐变（橙→黄→绿→青→蓝→紫），`blur(9px)` 柔化，中心用 radial mask 挖空——只留一圈光，不把整块染成彩色。拖得越远越明显，静止时完全不可见。
- **切页脉冲**：点按切换页面时，高亮块先快速鼓起（0.14 秒到 1.14 倍）再慢慢收回（0.24 秒），色散同步闪一次。

实现上把位移和缩放拆成两层：外层 `.tab-indicator` 只做 `translateX`，内层 `<i>` 只做 `scale`。两层各管一个 `transform`，互不覆盖，也不依赖 `scale`/`translate` 这类较新的独立变换属性，老 WebView 上降级只丢动效、不丢布局。

系统开启「减弱动态效果」时，以上动效全部关闭。

## 验证

新增 `_tools/nav-v5-check.mjs`，3 个视口 × 2 个主题 × 21 项断言：

| 检查组 | 断言 |
| --- | --- |
| 结构 | 4 个页面格、5 列网格、无 notes 格、加号存在 |
| 对齐 | 逐个切到 待办/AI/我的/首页，高亮块中心与格子中心偏差 ≤2px；块宽 = 1/5 栏宽 |
| 动效 | 静止 scale=1；拖 50% 得 1.075；拖满 1.15；切页 1.14；色散 conic 存在；静止 opacity=0；切页 opacity>0.5 |
| 入口 | 三处均能进入 `#/notes`；从「我的」进笔记后返回回「我的」 |
| 类型面板 | 弹出可见、三项齐全、不盖底栏、选完自动收起并打开「新建笔记」 |

实测结果：**三个视口的高亮块中心偏差全部为 0px**（不是"在容差内"，是完全重合），21 项断言全过。

另跑 `navbar-check.mjs`（底栏离屏幕距离、内容不被遮、AI 输入区位置）5 个视口全过，说明改格数没有破坏 2.9.0 建立的悬浮几何。

```

node _tools/nav-v5-check.mjs --dark     # 深色

```

## 升级说明

与 2.9.x 同一签名证书，**可直接覆盖安装，本地数据、配对令牌与登录态保留**，不需要重新配对。

底栏少了一个格子，如果之前习惯从底栏进笔记：现在走「我的 → 笔记」，或首页的「笔记」统计格 / 「最近笔记 → 全部」。

## 已知限制

- 类型选择器只放待办 / 笔记 / 提示词三项。速达与便签偏配置、不常新建，仍从「我的」进。
- 色散在浅色主题下比深色主题淡（白色背景上彩光对比度天然更低），这是配色结果，不是渲染差异。
- 其余七项（提醒时间、番茄钟自定义、强提醒、节日模块、首页时钟、增删入口改造）随 3.0.0 一起，见 `docs/11`。
