# 安卓端 3.0.0（versionCode 24）

新增「文件传输」：手机与电脑在同一 Wi-Fi 下互传文件，复用配对关系，不需要账号，也不经过任何云端。

## 新增

- **「我的 → 文件传输」**：状态卡、选择文件、传输中、未完成的发送、待接收、最近传输。
- **手机 → 电脑**：系统文件选择器（SAF，不申请存储权限）→ 2 MiB 分块 → AES-256-GCM → 电脑扩展收件箱。
- **电脑 → 手机**：扩展页选择文件 → 手机「待接收」→ 接收后落盘到 `下载/x-hub/`（Android 10+ 走 MediaStore）。
- **断点续传**：服务端按 `.part` 实际长度恢复；App 被杀后回页面有「未完成的发送 → 继续」，从记录的位置续传。
- **进度与重试**：块级进度、百分比、已传/总量、预计剩余；每块最多 5 次指数退避重试，4xx 不重试。
- **安全**：令牌派生 HKDF → AES-256-GCM，AAD 绑定任务与块序号；整文件 SHA-256 双端复核；可执行文件打红标但绝不自动打开。

## 限制

| 项 | 值 |
| --- | --- |
| 单文件 | 512 MiB |
| 电脑侧总配额 | 2 GiB |
| 待接收有效期 | 24 小时 |
| 本地保留 | 14 天 |

## 兼容性

- 同步协议仍是 `PROTO 2`，`versionCode 24` 可直接覆盖安装，本地待办/笔记不受影响。
- 电脑扩展需 **3.0.0** 才有文件面板；旧扩展下手机端会提示「电脑端需升级」，同步照常。
- 老设备记录没有 `allowFiles` 字段时按允许处理，无需重新配对。

## 升级后建议先试

1. 同一 Wi-Fi 下打开电脑扩展，手机进「文件传输」确认显示电脑地址。
2. 传一个几 MB 的文件，确认电脑收件箱出现且大小一致。
3. 传到一半关 Wi-Fi，再打开点「续传」，确认从断点继续而不是从头开始。
