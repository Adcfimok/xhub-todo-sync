# 待办同步 · 安卓端 v2.8.0

修复「同一 Wi-Fi 却配对不上」：电脑端可能给出虚拟网卡 / VPN 地址，而手机只拿到这一个地址就无从重试。
本版把配对升级为多候选地址 + 逐个尝试，并把失败原因显示在页面上。

## 本版变更

- **二维码载荷升级到 v3**：`xhub://3/<配对码>/<ip:port,...>`，一次带最多 4 个候选地址（物理网卡优先，虚拟网卡靠后）。
- **配对流程改为逐个尝试**：对每个候选地址先 `ping` 再 `pair`，任一成功即停止；全部失败时把最后一条真实原因显示在配对卡上，不再是笼统的「配对失败」。
- **手输地址同样走多候选**：手输一个地址时，仍会尝试该地址的常见邻居地址，避免用户手动抄错网卡。
- **设置页配对卡重做**：状态、候选数量、重试入口集中在同一张卡，配不上时不用来回翻页面。
- **首页与底栏位置**按 2.8 设计稿校正，中央 ＋ 随页面切换新建类型。

## 升级说明

与 2.7.0 同一签名证书，**可直接覆盖安装，本地数据与登录态保留**（数据保留机制见 `docs/06`）。

## 安装

1. 下载 `todo-link-2.8.0.apk`，允许「安装未知来源应用」。
2. 打开「我的 → 同步与设置」→ 扫码（推荐）或手输主地址 + 6 位配对码。
3. 配对成功后首页出现五类计数卡片。
