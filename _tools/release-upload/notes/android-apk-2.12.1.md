# 安卓端 2.12.1（versionCode 20）

按反馈回退 2.12.0 的卡片改动：统计恢复成一张 4×2 卡片里的四宫格，其余两项（时间与问好同行、节日一键添加）保留。

## 改了什么

| 位置 | 2.12.0 | 2.12.1 |
| --- | --- | --- |
| 首页统计 | 拆成四张 4×1 卡片，纵向占 4 行（约 342px） | 回退为一张 4×2「统计」卡，四个数字横向排一行，底部仍是「今天完成 N 件 · 已全部同步」 |
| 整卡点击 | 统计卡整张可点 | 恢复成四宫格里的小按钮，各自跳转 |
| 卡片库 | 10 → 13 项 | 回到 10 项，与 2.11.1 一致 |

保留未动：

- **时间与问好同一行**（2.12.0 新增）：时钟 38px + 问好 18px 基线对齐，跨时段自动更新。
- **我的 → 节日 → 一键添加所有节日**（2.12.0 新增）：批量写待办 / 一键撤回。

## 升级说明

- 已经装过 2.12.0 的机器，本地存的是四张统计卡的布局。2.12.1 读取时会自动合并回一张「统计」卡，落在第一张统计卡原来的位置，日历等卡片顺延，不会出现「统计整块消失」或空洞。
- 只删过其中一两张统计卡的，也会按剩下的合并成一张，不会重复。
- 合并是幂等的：再次读写不会多卡；`android/tests/home-layout.test.mjs` 覆盖了这几种情况。

## 验证

```
node _tools/home-check.mjs                                              # 75 项（统计卡断言改为「单张四宫格 + 无 stat:* 残留」）

node _tools/navbar-check.mjs                                            # 5 视口几何
node --experimental-default-type=module --test android/tests/*.test.mjs # 42 项（home-layout 8 项：合并迁移/幂等/minH/增删）
```

首页截图（360/390/430，浅色 + 暗色）与 2.11.1 的统计卡逐像素一致，仅首屏时间行不同。
