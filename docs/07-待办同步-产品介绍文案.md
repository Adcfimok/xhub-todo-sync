## 三、长描述（官网 / 商店详情正文）

### 手机和电脑之间，缺的从来不是网

你可能有过这样的时刻：在电脑前把今天的待办理得清清楚楚，一出门就只剩模糊的印象；手机上顺手记了半页灵感，回到工位还得照着屏幕再敲一遍。

我们不是没有工具，是工具之间那道缝没人补。

**待办同步**只做这一件事：把 x-hub 工作台上的待办、笔记、便签、速达和提示词，通过你家的局域网，直接送到安卓手机。手机上改完，回到同一张网里自动合并回去。

没有账号，没有云盘，也没有一个"我们承诺不会看"的服务器——因为数据压根没离开过你的网络。

### 核心功能

**① 扫码即连，五类内容一起走**
电脑端出二维码或 6 位配对码，手机扫一下就连上。待办、笔记、便签、速达、提示词全部跟随，不是只同步一个清单，而是把整张工作台搬过去。

**② 它知道该用哪张网卡**
装了 VPN、VMware、VirtualBox、Hyper-V、WSL、Docker 的电脑，往往有一堆 192.168 开头的地址，而手机一张也连不上。扩展不按网段猜，而是问操作系统"默认路由走哪张卡"，虚拟网卡再降权处理。配对页会直接标出哪一个是主地址、哪些是虚拟网卡、为什么连不上。

这一条听起来不性感，但它是"扫码之后一直转圈"的真正解药。

**③ 离线可改，回来自动合并**
地铁里、电梯里、会议室没信号的地方，照常改。每条记录带混合逻辑时钟，重新入网时逐条比对，后写的胜出——不是整表覆盖，也不会把手机上的新内容冲掉。

**④ 删除有墓碑，空快照不误删**
删掉的条目会留下 30 天墓碑，不会出现"删了的待办自己爬回来"；反过来，一次读空的快照也不会被当成"全部删光"，你的笔记不会因为一次读取失败而消失。

**⑤ 手机变成第二块屏**
手机端可以加载你装在电脑上的其他 x-hub 扩展，样式和逻辑照常运行，读到的就是电脑里的真实数据。手机上顺手打开一个倒计时、一个速查表，不用再为它单独找个 App。

**⑥ 工作台卡片，一眼扫完**
紧凑（2×2）和标准（4×3）两种尺寸，纯容器查询自适应。待完成、今日到期、待回写三个数字，加最近三条待办，再配一个状态点：在线、同步中、有冲突、离线、后端未响应。

### 主要特性

| 特性 | 说明 |
|---|---|
| 配对方式 | 二维码 / 6 位配对码，5 分钟有效，最多绑定 8 台设备 |
| 网卡识别 | 按系统默认路由选地址，虚拟网卡降权，可手动切换并复制 |
| 同步节奏 | 默认 15 秒一轮，SSE 实时推送变更，也可随时「立即同步」 |
| 合并策略 | 记录级后写胜出 + 混合逻辑时钟，不整表覆盖 |
| 删除保护 | 墓碑保留 30 天；空快照需连续确认才判定删除 |
| 写回边界 | 手机可改待办（标题 / 完成 / 优先级 / 截止 / 备注）与便签内容，其余只读 |
| 设备管理 | 在线状态实时可见，随时移除，移除即失效 |
| 权限自检 | 权限未开时红条提示 + 一键跳转设置，不会假装"已就绪" |
| 状态可见 | 卡片与页脚显示同步时间、待回写条数、冲突数、错误原因 |

### 适用场景

- **通勤路上核对今天**：出门前理好的待办，在地铁里逐条划掉，没信号也不影响。
- **开会随手记**：手机上记的要点，回到工位笔记已经躺在电脑里。
- **公司家里两头跑**：两台机器各自入网即续上，不用带 U 盘，也不用登同一个账号。
- **常用语料随身带**：提示词、速达资源在手机上直接调用，不必翻聊天记录找。
- **不愿把个人安排交给云服务**：数据留在自己网内，这是硬要求而不是选项。

### 你能得到什么

- **少一次搬运**：不用复制、不用粘贴、不用二次录入。
- **断网照用**：本地优先，网络只是通道，不是前提。
- **数据自己拿着**：无账号、无云端、无使用统计。
- **改错也有退路**：冲突留档可查，删除有墓碑兜底，误读不会清库。
- **状态心里有数**：有没有同步上，卡片上的一个点就说明了。

### 隐私与安全

- 数据只在你自己的电脑上落盘，路径就是扩展目录下的 `.data/hub.json`，可自行备份或清理。
- 配对成功才发令牌，请求按设备鉴权；配对、设备、清理这些管理接口只接受本机访问。
- 无账号体系，不收集通讯录、位置、设备标识或使用行为。
- 扩展只申请四项权限：读数据、写数据、局域网通信、桌面通知，每一项在系统里都能单独关掉。
- 除局域网同步外不产生任何外部请求，也没有遥测。

### 兼容与要求

| 项目 | 要求 |
|---|---|
| 电脑端 | x-hub 桌面版（Windows / macOS / Linux），扩展 v2.1.0 |
| 手机端 | 安卓 App v2.8 及以上，需与电脑处于同一局域网 |
| 网络 | 同一 Wi-Fi 或同一有线局域网；默认端口 47821 |
| 运行时 | Node 18+（由 x-hub 内置提供，无需单独安装） |

## 五、常见问题（可放商店页底部）

**需要注册登录吗？**
不需要。配对码换令牌，设备之间直接认，没有账号这一层。

**数据会上传云端吗？**
不会。同步只走局域网；电脑关机时手机用本地副本，重新入网后合并。

**手机能改哪些内容？**
待办（标题、完成状态、优先级、截止时间、备注）和便签内容可写；笔记、速达、提示词只读，避免误改。

**电脑关了手机还能看吗？**
能。已同步的内容留在手机本地，可离线查看和编辑；电脑重新上线后自动合并。

**最多连几台设备？**
8 台。每台都能单独移除，移除后令牌立即失效。

**会不会把删掉的待办同步回来？**
不会。删除会留下 30 天墓碑，合并时以墓碑为准。
