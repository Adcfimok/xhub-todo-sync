# x-hub 卡片适配样式设计规范（v1.0）

> 适用对象：x-hub 工作台 `module` 形态扩展卡、以及需要与 x-hub 视觉保持一致的独立端界面（本项目的 Android 端）。
> 依据：`x-hub` v0.9.7 源码（`.dash-grid` / `.dash-cell` / `ExtensionView` / 内置卡片）+ `todo-countdown-ext 1.1.0` 实机卡片 + 官方 `theming.md` / `surfaces.md`。
> 定位：**可执行规范**——每条规则都能落到一段 CSS，验收时能对着截图量。

---

## 0. 一句话原则

> 卡片不是「缩小版页面」，而是**同一份数据在有限面积下的最优表达**。
> 面积不够就减信息层级，不是减字号到看不清；面积变大就加信息层级，不是把元素拉大。

---

## 1. 几何基准

### 1.1 栅格

| 项 | 值 | 来源 |
|---|---|---|
| 列数 | 12 | `.dash-grid { grid-template-columns: repeat(12, minmax(0,1fr)) }` |
| 列间距 | 16px | `gap: var(--space-4)` |
| 网格外边距 | 上 0、右 20、下 20、左 0 | `padding: 0 20px 20px 0` |
| 行高下限 | 36px | `--dash-row-min: 36px` |
| 卡片圆角 | 12px | `--radius-lg` |
| 卡片外壳 | 玻璃渐变 + 1px 半透明白描边 + 双层阴影 | `.card { background: var(--frost-surface) }` |

### 1.2 卡片尺寸换算

```
cw = (W − S − 20 − 176) / 12          // 单格宽
Wc = w × cw + (w − 1) × 16            // 占 w 列的卡宽
rh = max(36, (H − 20 − (R−1)×16) / R) // 行高
Hc = h × rh + (h − 1) × 16            // 占 h 行的卡高
```

`W` 窗口宽、`S` 侧栏宽（展开 220 / 折叠 56）、`R` 总行数、`H` 工作区高（= 窗高 − 48）。

实机标定（1236×900，侧栏展开）：

| w | 卡宽 | | h | 卡高 | 内容区（有表头，减 30+24） |
|---|---|---|---|---|---|
| 1 | 68 | | 1 | 36 | 无效（放不下） |
| 2 | 153 | | 2 | 88 | 34 |
| 3 | 221 | | 3 | 140 | 86 |
| 4 | 289 | | 4 | 192 | 138 |
| 6 | 426 | | 6 | 296 | 242 |

> **红线**：任何内容都必须能在 **153×88（内容区 153×34）** 下不溢出、不裁切、不出现滚动条。

### 1.3 内边距

| 位置 | 值 | 说明 |
|---|---|---|
| 卡片内容区四边 | **12px** | 与内置卡一致；`box-sizing: border-box` 必写 |
| 宿主表头 | `padding: 12px 12px 0` | 宿主绘制，扩展不要重复画标题 |
| 表头下沿到内容 | 0 | iframe 已从表头下方开始 |
| 格子过矮时 | 不删内边距 | 用 `clamp(8px, 4cqh, 12px)` 收缩，不要贴边 |

## 2. 容器查询：卡片的「媒体查询」

扩展卡内容区必须自建查询容器：

```css
body {
  height: 100%;
  margin: 0;
  padding: 12px;
  box-sizing: border-box;
  container: card / size;   /* 命名容器：子孙可用 cqh/cqw 与 @container */
  overflow: hidden;
  background: transparent;  /* 外壳由宿主画 */
}
```

### 2.1 尺寸分级（按内容区高度，不看窗口）

| 级别 | 内容区高 | 信息容量 | 典型占位 |
|---|---|---|---|
| **XS** | < 60px | 1 个主指标 + 1 条状态；或单行列表 1 项 | 2×2 且有表头 |
| **S** | 60–110px | 2–3 个指标并排；或 2 行列表 | 2×2 无表头 / 3×2 |
| **M** | 110–200px | 指标带 + 2–3 行明细 | 4×3 |
| **L** | > 200px | 指标带 + 分组列表 + 操作区 | 4×6 / 6×6 |

判定用容器查询，不用 JS 量高：

```css
@container card (min-height: 60px)  { .only-xs { display: none } }
@container card (min-height: 110px) { .tiles { grid-template-columns: repeat(3,1fr) } }
@container card (min-height: 200px) { .rows .row:nth-child(n+4) { display: flex } }
```

> 只写「向上增强」：默认按 XS 排，`min-height` 逐级放开更多元素。这样任何没命中的极端尺寸都退化到最保守的布局，而不是塌成空白。

### 2.2 形态（variant）与尺寸分级的分工

| 机制 | 决定什么 | 触发方式 |
|---|---|---|
| `moduleVariants` | **结构**（显示哪几块内容） | 用户在布局编辑器选，宿主写 `data-xhub-variant` 并广播 `xhub:variant-changed` |
| 容器查询 | **密度**（同一结构下字号、间距、可见行数） | 纯 CSS，随格子大小自动 |
| `clamp()` + `cqh` | **连续缩放**（字号、间隙的平滑过渡） | 纯 CSS |

三者叠加顺序：先按 variant 定骨架 → 再用容器查询定元素显隐 → 最后用 clamp 微调数值。

## 3. 排版阶梯

所有字号以内容区高度为基准（`cqh` = 内容区高的 1%），并给上下限，避免极端值。

| 令牌 | 用途 | 公式 | 153×34 下 | 289×138 下 | 字重 | 其它 |
|---|---|---|---|---|---|---|
| `--fs-metric` | 主数字 | `clamp(16px, 13cqh, 26px)` | 16 | 18 | 650 | `tabular-nums`，`letter-spacing:-.02em` |
| `--fs-title` | 卡内小标题（自绘时） | `clamp(11px, 6.4cqh, 13px)` | 11 | 9→13 | 600 | `letter-spacing:-.01em` |
| `--fs-body` | 列表主文 | `clamp(11px, 6.8cqh, 13px)` | 11 | 13 | 500 | 单行 `ellipsis` |
| `--fs-label` | 指标名 / 次要 | `clamp(9.5px, 5.6cqh, 11px)` | 9.5 | 11 | 500 | 色 `text-3` |
| `--fs-badge` | 徽标 / 计数 | `clamp(9px, 5cqh, 10.5px)` | 9 | 10.5 | 600 | `tabular-nums` |

硬规则：

1. **下限不低于 9px**。低于 9px 在中文字形上糊成一团，宁可减内容。
2. **同一张卡最多 3 级字号**（主数字 / 正文 / 辅助）。出现第 4 级说明信息层级该砍了。
3. **数字一律 `font-variant-numeric: tabular-nums`**，否则刷新时宽度跳动。
4. 标题不换行、不省略到 2 字以下：`overflow:hidden; text-overflow:ellipsis; white-space:nowrap`。
5. 中文不设 `letter-spacing` 正值；负值仅用于大号数字（`-0.02em`）。

---

## 4. 间距阶梯

| 令牌 | 公式 | 用途 |
|---|---|---|
| `--gap-page` | `12px`（矮卡 `clamp(8px,4cqh,12px)`） | 卡片内边距 |
| `--gap-block` | `clamp(4px, 3cqh, 8px)` | 区块之间（指标带 ↔ 列表） |
| `--gap-item` | `clamp(2px, 1.6cqh, 5px)` | 列表行之间 |
| `--gap-inline` | `8px`（矮卡 `6px`） | 行内元素（点 + 文本 + 数值） |
| `--pad-tile` | `clamp(3px,2cqh,6px) clamp(6px,1.6cqw,9px)` | 磁贴内边距 |

规则：**块间距 > 行间距 > 行内间距**，三级至少差 2px，否则视觉上分不清层级。

## 5. 颜色与语义

### 5.1 令牌来源

只允许用宿主注入变量 + 单层兜底：

```css
--ink:   var(--xhub-text-1, #1f2230);
--ink-2: var(--xhub-text-2, #5b6070);
--ink-3: var(--xhub-text-3, #8b90a0);
--line:  var(--xhub-border, rgba(0,0,0,.10));
--well:  var(--xhub-bg-card, rgba(255,255,255,.9));
--accent:var(--xhub-accent, #5b6cff);
--red / --orange / --amber / --blue / --green
```

- **不要** `color-mix()` / 相对颜色语法：宿主 WebView 版本参差，一条不支持的颜色声明会让整条 `background` 失效，表现就是「卡片一片空白」。
- 浅色主题下琥珀色必须换深值（亮黄在白底不可读）：`--amber: #9a6a00`；深色主题再用 `--xhub-yellow`。

### 5.2 语义色分配（唯一映射表）

| 语义 | 颜色 | 用在哪 |
|---|---|---|
| 逾期 / 失败 / 断开 | `--red` | 数值、行首圆点、状态徽标 |
| 临期 / 警告 / 待处理 | `--orange` | 同上 |
| 提示 / 中性强调 | `--amber`（浅色深琥珀） | 同上 |
| 进行中 / 信息 | `--blue` | 同步中、连接中 |
| 正常 / 已连接 / 完成 | `--green` | 在线徽标、完成态 |
| 禁用 / 无数据 | `--ink-3` | 占位、次要说明 |

**一色一义**：同一张卡里绿色不能既表示「完成」又表示「在线」。需要区分时用形状/位置，不新增颜色。

### 5.3 明暗与壁纸

```css
:root { color-scheme: light; }
:root[data-xhub-theme='dark'] { color-scheme: dark; /* 重写全部兜底值 */ }

/* 真实透底（壁纸 + 玻璃透明度低）：去白描边、只留中性落影，文字加一档柔光 */
:root[data-xhub-wallpaper-clear='1'] .tile { border-color: transparent; box-shadow: 0 1px 2px rgba(0,0,0,.18); }
:root[data-xhub-wallpaper-clear='1'] body { text-shadow: 0 1px 2px rgba(0,0,0,.28); }
```

- 卡片底：**module 卡永远 `background: transparent`**（宿主已铺玻璃）。自绘子表面才用 `--well` 或 `rgba(0,0,0,.035)`（深色下 `rgba(255,255,255,.06)`）。
- 整页（view/window/drawer）：`body { background: var(--xhub-page-bg, transparent) }`。

## 6. 原子组件规范

### 6.1 指标磁贴（Metric Tile）

```
┌──────────────┐
│  12          │  ← --fs-metric，语义色按需
│  待完成       │  ← --fs-label，--ink-3
└──────────────┘
```

- 底：`rgba(0,0,0,.035)` / 深色 `rgba(255,255,255,.06)`，圆角 8px，1px `--line` 描边。
- 一行最多 3 个；4 个以上改两行或降级为「主指标 + 其余合并」。
- 数字与标签都**不许换行**；标签超长省略。
- 数值为 0 时保留磁贴（显示 0），不要隐藏——消失的元素会让用户以为坏了。

### 6.2 列表行（Row）

```
● 写周报                    3 天
↑ 6px 圆点   ↑ flex:1 省略    ↑ 右对齐 tabular-nums 语义色
```

- 行高：`clamp(16px, 9cqh, 24px)`；行间 `--gap-item`。
- 圆点 6px，是**唯一的行首状态标记**，不要再用左边框。
- 右侧数值右对齐、等宽数字。
- 行数按容器高度放开：XS 1 行 / S 2 行 / M 3 行 / L 6 行，多余 `overflow:hidden` 并显示「+N」。

### 6.3 状态徽标（Badge）

- 形态：`padding: 1px 6px; border-radius: 999px; font-size: var(--fs-badge)`。
- 底色 = 语义色 12% 透明，文字 = 语义色。
- 文案 ≤ 4 个汉字：`在线` `离线` `同步中` `冲突`。

### 6.4 进度条

- 高 3px（矮卡 2px），圆角 999px，底 `--line`，填充 `--accent`。
- 只用于「有明确总量的任务」，不要用于不确定进度（用「同步中」徽标 + 呼吸动画）。

### 6.5 空态 / 错误态

| 态 | 结构 | 文案规则 |
|---|---|---|
| 空 | 居中，1 行标题 + 1 行说明 | 「还没有待办」/「添加后会显示在这里」 |
| 加载 | 居中 1 行 | 「读取中…」；矮卡只保留省略号 |
| 错误 | 居中 1 行原因 + 重试按钮 | 原因 ≤ 60 字，禁止堆栈 |

- 错误色用 `--red`，但**不要整卡变红底**。
- 重试按钮尺寸 ≥ 24×24，`stopPropagation` 防止触发卡片跳转。

## 7. 溢出与截断

1. `body { overflow: hidden }` 是最后一道防线，**不是**布局手段。
2. 纵向空间不足时，按此顺序牺牲：装饰 → 次要说明 → 列表行数（保留 1 行）→ 指标带改为单指标。
3. 横向不足时：先缩省略标题，再隐藏单位后缀，**不要**让数值被截断。
4. 任何 `text-overflow: ellipsis` 必须配 `min-width: 0`（flex 子项默认 `min-width:auto` 不收缩）。

---

## 8. 交互与可访问性

| 项 | 规范 |
|---|---|
| 整卡可点 | 绑定在容器上，子按钮 `stopPropagation` |
| 命中区 | 可点元素 ≥ 24×24；行整行可点 |
| 焦点 | `:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px }` |
| 语义 | 用 `<button>` / `<section aria-label>`，不要 div 冒充 |
| 数字播报 | `aria-live="polite"` 只给状态徽标，不要给每秒刷新的计时 |
| 动效 | ≤ 200ms；`@media (prefers-reduced-motion: reduce)` 全部关闭 |
| 主题切换 | 不重建 DOM，只切属性 |

---

## 9. 与宿主表头的协作

| 场景 | 规则 |
|---|---|
| `moduleOptions.defaultHideTitle: false` | 宿主画表头（14px 品牌色图标 + 13px/600 标题）；卡面**不要**再画同名标题 |
| 未声明（默认） | 无表头；卡面自己决定要不要一行小标题 |

表头占约 30px，会直接吃掉内容区高度——**声明表头前先确认 XS 尺寸下还剩得下内容**。

## 10. 验收清单（逐条可测）

- [ ] 153×34 内容区：无滚动条、无文字被裁半行、无元素重叠
- [ ] 153×88 / 289×138 / 426×242 三档：信息层级依次递增，不是等比放大
- [ ] 深浅主题切换：无「白底白字」，无残留白描边
- [ ] 壁纸 + 透底：卡片底不遮壁纸，文字可读
- [ ] 所有数字等宽，刷新不跳动
- [ ] 空 / 加载 / 错误 三态都有，错误可重试
- [ ] 缩放窗口到 800px 宽：卡片不破版
- [ ] 键盘 Tab 一圈：焦点可见，顺序合理
- [ ] 无 `color-mix` / 无 CDN / 无外链字体
- [ ] 字号最小 ≥ 9px，最小命中区 ≥ 24px

## 11. 落地代码

规范的可执行形态见扩展目录 `shared/tokens.css`（令牌）与 `module/index.html`（骨架）。
Android 端复用同一份 `tokens.css`，仅把 `--xhub-*` 的兜底值改为移动端基色，保证两端视觉同源。
